Autoplace API Documentation

This document gives a quick overview of what to expect after integrating this API and using it subequently.
We have included a sample response that would be received over the network for queries in English and in a 
non-English language.

For a query in English, say "mumbai", the API will send a GET reuqest with the payload mentioned below.

Headers
Request URL        https://autoplaces.drivado.com/api/v1/autocomplete?input=mumbai&lang=en&limit=7
Request Method     GET
Status Code        200 OK

Payload
input  mumbai
lang   en
limit  7
